# Оплата за клик

> Раздел справочника [Ozon Performance API](../README.md). Базовый URL: `https://api-performance.ozon.ru`. Аутентификация: заголовок `Authorization: Bearer <token>`.

Методы для работы с товарными кампаниями с оплатой за клики (CPC): создание кампаний, управление товарами и ставками.

Управление жизненным циклом кампаний (активация, выключение, изменение параметров, расчёт минимального бюджета) описано в разделе [Кампании и рекламируемые объекты](campaigns.md).

В этом разделе:

- [Создать кампанию с оплатой за клики](#создать-кампанию-с-оплатой-за-клики) — `POST /api/client/campaign/cpc/v2/product`
- [Добавить товары в кампанию](#добавить-товары-в-кампанию) — `POST /api/client/campaign/{campaignId}/products`
- [Обновить ставки товаров](#обновить-ставки-товаров) — `PUT /api/client/campaign/{campaignId}/products`
- [Список товаров кампании](#список-товаров-кампании) — `GET /api/client/campaign/{campaignId}/v2/products`
- [Удалить товары из кампании](#удалить-товары-из-кампании) — `POST /api/client/campaign/{campaignId}/products/delete`
- [Конкурентные ставки для товара](#конкурентные-ставки-для-товара) — `GET /api/client/campaign/{campaignId}/products/bids/competitive`

## Создать кампанию с оплатой за клики

```http
POST /api/client/campaign/cpc/v2/product
```

Метод для создания товарной рекламной кампании с оплатой за клики.

При успешном выполнении запроса в поле `campaignId` ответа будет идентификатор созданной кампании.

### Тело запроса

| Поле | Тип | Обязательный | Описание |
|---|---|---|---|
| `title` | string | Нет | Название рекламной кампании |
| `fromDate` | string | Нет | Дата начала рекламной кампании по московскому времени. Если параметр не заполнен, датой старта считается начало текущего дня. Открутка начинается сразу после активации кампании, если не нужна модерация |
| `toDate` | string | Нет | Дата окончания рекламной кампании по московскому времени. Параметр не учитывается для кампаний с оплатой за клики, созданных в автоматическом режиме |
| `dailyBudget` | string \<uint64\> | Нет | **Deprecated.** Ограничение дневного бюджета рекламной кампании. Единица измерения — одна миллионная доля рубля, округляется до копеек. Например, значение 1 000 000 в параметре равно 1 рублю. Если параметр не заполнен, дневной бюджет не ограничен. После создания рекламной кампании изменить бюджет с дневного на недельный и наоборот не получится |
| `weeklyBudget` | string \<uint64\> | Нет | Ограничение недельного бюджета рекламной кампании. Единица измерения — одна миллионная доля рубля, округляется до копеек. Например, значение 1 000 000 в параметре равно 1 рублю. Если параметр не заполнен, недельный бюджет не ограничен. После создания рекламной кампании изменить бюджет с недельного на дневной и наоборот не получится |
| `placement` | string | Да | Место размещения продвигаемых товаров. Default: `PLACEMENT_INVALID`. Enum: `PLACEMENT_TOP_PROMOTION` — поиск; `PLACEMENT_INVALID` — не определено; `PLACEMENT_SEARCH_AND_CATEGORY` — поиск и рекомендации |
| `productAutopilotStrategy` | string | Нет | Стратегия, которая будет использоваться для кампании. Enum: `MAX_CLICKS` — автостратегия для Поиска и рекомендаций; `TOP_MAX_CLICKS` — автостратегия для Поиска; `TARGET_BIDS` — средняя стоимость клика для Поиска и рекомендаций; `TOP_PROMOTION` — вывод в топ; `TARGET_CIR` — целевой расход |

### Ответ 200 — Кампания создана

| Поле | Тип | Описание |
|---|---|---|
| `campaignId` | string \<uint64\> | Идентификатор кампании |

**Пример запроса:**

```http
POST /api/client/campaign/cpc/v2/product HTTP/1.1
Host: api-performance.ozon.ru:443
Content-Type: application/json
Accept: application/json
Authorization: Bearer <token>
```

```json
{
  "title": "string",
  "fromDate": "string",
  "toDate": "string",
  "dailyBudget": "string",
  "weeklyBudget": "string",
  "placement": "PLACEMENT_INVALID",
  "productAutopilotStrategy": "MAX_CLICKS"
}
```

**Пример ответа (200):**

```json
{
  "campaignId": "string"
}
```

**Ошибка:** `default` — ошибка запроса.

## Добавить товары в кампанию

```http
POST /api/client/campaign/{campaignId}/products
```

Добавляет товары в кампанию с оплатой за клик. В кампанию можно добавить не более **500 товаров**.

Рекомендации по заполнению параметров для разных кампаний:

- Для добавления в кампанию товаров передайте значения параметров `sku` и `bid`. Если параметр `bid` не указан, автоматически задаётся конкурентная ставка.
- Параметр `bid` учитывается только для кампании с включённой стратегией «Средняя стоимость клика».
- Для кампании с включённой стратегией можно добавлять товары только из категории `autopilot.categoryId`.

### Параметры пути (path)

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `campaignId` | string \<uint64\> | Да | Идентификатор кампании |

### Тело запроса

| Поле | Тип | Обязательный | Описание |
|---|---|---|---|
| `bids` | array of objects | Нет | Ставки за клики |
| `bids[].sku` | string \<uint64\> | Нет | Идентификатор товара: Ozon ID или SKU |
| `bids[].bid` | string | Нет | Ставка за клик |
| `bids[].targetCir` | number | Нет | Целевая доля рекламных расходов в процентах (для стратегии «Целевой расход») |
| `bids[].topPosition` | string | Нет | Диапазон позиций в поиске для стратегии «Вывод в топ»: `Топ-4`, `Топ-12`, `Топ-20`, `Топ-30` |

### Ответ 200 — Товары добавлены в кампанию

Успешный ответ не содержит тела.

**Ошибка:** `default` — ошибка запроса:

```json
{
  "error": "text"
}
```

**Пример запроса:**

```http
POST /api/client/campaign/48852/products HTTP/1.1
Host: api-performance.ozon.ru:443
Content-Type: application/json
Accept: application/json
Authorization: Bearer <token>
```

```json
{
  "bids": [
    {
      "sku": "string",
      "bid": "string",
      "targetCir": 15,
      "topPosition": "Топ-20"
    }
  ]
}
```

## Обновить ставки товаров

```http
PUT /api/client/campaign/{campaignId}/products
```

Обновляет ставки товаров в кампании.

> Этот метод перезаписывает список стоп-слов и фразы со ставками. Исходные стоп-слова и фразы со ставками удаляются.

Чтобы обновить ставки в кампании с размещением в карточке товара, передайте значения параметров `sku` и `bid`.

Параметр `bid` учитывается только для кампании с включённой стратегией «Средняя стоимость клика».

### Параметры пути (path)

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `campaignId` | string \<uint64\> | Да | Идентификатор кампании |

### Тело запроса

| Поле | Тип | Обязательный | Описание |
|---|---|---|---|
| `bids` | array of objects | Нет | Ставки за клики |
| `bids[].sku` | string \<uint64\> | Нет | Идентификатор товара: Ozon ID или SKU |
| `bids[].bid` | string | Нет | Ставка за клик |
| `bids[].targetCir` | number | Нет | Целевая доля рекламных расходов в процентах (для стратегии «Целевой расход») |
| `bids[].topPosition` | string | Нет | Диапазон позиций в поиске для стратегии «Вывод в топ»: `Топ-4`, `Топ-12`, `Топ-20`, `Топ-30` |

### Ответ 200 — Ставки обновлены

Успешный ответ не содержит тела.

**Ошибка:** `default` — ошибка запроса:

```json
{
  "error": "text"
}
```

**Пример запроса:**

```http
PUT /api/client/campaign/48852/products HTTP/1.1
Host: api-performance.ozon.ru:443
Content-Type: application/json
Accept: application/json
Authorization: Bearer <token>
```

```json
{
  "bids": [
    {
      "sku": "string",
      "bid": "string",
      "targetCir": 15,
      "topPosition": "Топ-20"
    }
  ]
}
```

## Список товаров кампании

```http
GET /api/client/campaign/{campaignId}/v2/products
```

Возвращает список товаров в кампании с оплатой за клик с текущими ставками.

### Параметры пути (path)

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `campaignId` | string \<uint64\> | Да | Идентификатор кампании |

### Параметры запроса (query)

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `page` | integer \<int64\> | Нет | Номер страницы |
| `pageSize` | integer \<int64\> | Нет | Размер страницы |

### Ответ 200 — Список товаров кампании

| Поле | Тип | Описание |
|---|---|---|
| `products` | array of objects | Список товаров кампании |
| `products[].sku` | string \<uint64\> | Идентификатор товара: Ozon ID или SKU |
| `products[].bid` | string \<uint64\> | Только для стратегии «Средняя стоимость клика». Ставка за один клик — CPC |
| `products[].targetCir` | number \<double\>, диапазон 10..100 | Только для стратегии «Целевой расход». Целевая доля рекламных расходов в процентах. Default: 15 |
| `products[].title` | string | Название товара |
| `products[].topPosition` | string \<uint64\> | Только для стратегии «Вывод в топ». Диапазон позиций в поиске: `Топ-4`, `Топ-12`, `Топ-20` (default), `Топ-30` |

**Пример запроса:**

```http
GET /api/client/campaign/48852/v2/products?page=1&pageSize=100 HTTP/1.1
Host: api-performance.ozon.ru:443
Authorization: Bearer <token>
```

**Пример ответа (200):**

```json
{
  "products": [
    {
      "sku": "string",
      "bid": "string",
      "targetCir": 15,
      "title": "string",
      "topPosition": "Топ-20"
    }
  ]
}
```

**Ошибка:** `default` — ошибка запроса.

## Конкурентные ставки для товара

```http
GET /api/client/campaign/{campaignId}/products/bids/competitive
```

Возвращает конкурентные ставки для товаров в кампании.

Если товар не добавлен в кампанию, в параметре `bid` будет значение `0`. В одном запросе вы можете передать до **200 товаров**.

### Параметры пути (path)

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `campaignId` | string | Да | Идентификатор кампании |

### Параметры запроса (query)

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `skus` | array of string | Да | Список SKU товаров |

### Ответ 200 — Конкурентные ставки

| Поле | Тип | Описание |
|---|---|---|
| `bids` | array of objects | Список ставок |
| `bids[].bid` | string | Значение конкурентной ставки |
| `bids[].sku` | string | SKU товара |
| `campaignId` | string | Идентификатор кампании |

**Пример запроса:**

```http
GET /api/client/campaign/48852/products/bids/competitive?skus=123456&skus=789012 HTTP/1.1
Host: api-performance.ozon.ru:443
Authorization: Bearer <token>
```

**Пример ответа (200):**

```json
{
  "bids": [
    {
      "bid": "string",
      "sku": "string"
    }
  ],
  "campaignId": "string"
}
```

**Ошибка:** `default` — ошибка запроса.
