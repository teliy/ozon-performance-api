# Статистика и отчёты

> Раздел справочника [Ozon Performance API](../README.md). Базовый URL: `https://api-performance.ozon.ru`. Аутентификация: заголовок `Authorization: Bearer <token>`.

> **Важно:** даты в отчётах рекламного кабинета группируются по московскому времени.

Порядок получения отчёта кампании:

1. Отправьте запрос на генерацию отчёта.
2. Получите сгенерированный отчёт по UUID запроса.

Performance API асинхронный: в результате запроса на генерацию возвращается не сам отчёт, а уникальный идентификатор отправленного запроса (`UUID`), с помощью которого можно проверить статус формирования отчёта и скачать отчёт. Формат отчёта по умолчанию — CSV; для большинства генераторов доступен JSON — добавьте `/json` в адрес метода.

## Статистика по кампании

```http
POST /api/client/statistics
```

Формирует отчёт по кампаниям. В запросе укажите временной промежуток с помощью полей `from` и `to` или `dateFrom` и `dateTo`. Если заполнены все четыре поля, в ответе будет статистика по временному промежутку из полей `dateFrom` и `dateTo`.

Performance API асинхронный. Поэтому в результате запроса будет не сам отчёт, а уникальный идентификатор отправленного запроса, с помощью которого можно проверить статус формирования отчёта и скачать отчёт. Формат отчёта — CSV.

Архивы с примерами отчётов для разных типов кампаний: Баннеры и нативные баннеры, Видеобаннеры, Оплата за клик.

Чтобы запросить отчёт в формате JSON, добавьте в адрес метода `/json` и отправьте запрос по адресу `/api/client/statistics/json`.

### Тело запроса

| Поле | Тип | Обязательный | Описание |
|---|---|---|---|
| `campaigns` | array of string \<uint64\> | Да | Список идентификаторов кампаний, для которых необходимо подготовить отчёт. Формат отчёта: CSV — если в списке одна кампания; ZIP-архив — если в списке несколько кампаний. Каждый файл соответствует одной кампании из списка. Имя файла вида `<идентификатор кампании>.csv` |
| `from` | string \<date-time\> | Нет | Начальная дата периода отчёта в формате RFC 3339. Максимальный период, за который можно получить отчёт — 62 дня |
| `to` | string \<date-time\> | Нет | Конечная дата периода отчёта в формате RFC 3339. Максимальный период — 62 дня |
| `dateFrom` | string | Нет | Начальная дата периода отчёта в формате ГГГГ-ММ-ДД. Например: `2019-02-10` |
| `dateTo` | string | Нет | Конечная дата периода отчёта в формате ГГГГ-ММ-ДД. Например: `2019-02-10` |
| `groupBy` | string | Нет | Тип группировки по времени. Default: `NO_GROUP_BY`. Enum: `DATE` — группировка по дате (по дням); `START_OF_WEEK` — группировка по неделям; `START_OF_MONTH` — группировка по месяцам |

### Ответ 200 — Статистика по кампании

| Поле | Тип | Описание |
|---|---|---|
| `UUID` | string | Уникальный идентификатор отправленного запроса. По нему можно проверить статус формирования отчёта и скачать отчёт |
| `vendor` | boolean | Если запрашивается отчёт с аналитикой внешнего трафика — `true` |

**Пример запроса:**

```http
POST /api/client/statistics HTTP/1.1
Host: api-performance.ozon.ru:443
Content-Type: application/json
Accept: application/json
Authorization: Bearer <token>
```

```json
{
  "campaigns": [
    "string"
  ],
  "from": "2019-08-24T14:15:22Z",
  "to": "2019-08-24T14:15:22Z",
  "dateFrom": "string",
  "dateTo": "string",
  "groupBy": "NO_GROUP_BY"
}
```

**Пример ответа (200):**

```json
{
  "UUID": "0c159c60-ab92-46d9-9a6b-d225dbf5c7b1",
  "vendor": true
}
```

**Ошибка:** `default` — ошибка запроса.

## Статус отчёта

```http
GET /api/client/statistics/{UUID}
```

Проверяет статус формирования отчёта и возвращает ссылку на скачивание.

### Параметры пути (path)

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `UUID` | string | Да | Уникальный идентификатор запроса |

### Ответ 200 — Статус отчёта

| Поле | Тип | Описание |
|---|---|---|
| `UUID` | string | Уникальный идентификатор запроса, для которого производилась проверка |
| `state` | string | Текущее состояние запроса. Default: `NOT_STARTED`. Enum: `NOT_STARTED` — запрос ожидает выполнения; `IN_PROGRESS` — запрос выполняется в данный момент; `ERROR` — выполнение запроса завершилось ошибкой; `OK` — запрос успешно выполнен |
| `createdAt` | string \<date-time\> | Дата и время получения запроса сервером, часовой пояс UTC |
| `updatedAt` | string \<date-time\> | Дата и время последнего обновления состояния запроса, часовой пояс UTC |
| `request` | object | Структура исходного запроса |
| `error` | string | Краткое описание возникшей ошибки. Поле присутствует, если выполнение запроса завершилось ошибкой |
| `link` | string | Относительная ссылка на отчёт в формате CSV. Поле присутствует, если запрос выполнен успешно |
| `kind` | string | Тип запрашиваемого отчёта. Default: `STATS`. Enum: `STATS` — отчёт по кампании; `SEARCH_PHRASES` — отчёт по поисковым фразам и по категории товаров; `ATTRIBUTION` — отчёт по заказам для оплаты за заказ; `VIDEO` — отчёт по показам видеобаннера |

**Пример запроса:**

```http
GET /api/client/statistics/0c159c60-ab92-46d9-9a6b-d225dbf5c7b1 HTTP/1.1
Host: api-performance.ozon.ru:443
Authorization: Bearer <token>
Content-Type: application/json
Accept: application/json
```

**Пример ответа (200):**

```json
{
  "UUID": "0c159c60-ab92-46d9-9a6b-d225dbf5c7b1",
  "state": "OK",
  "createdAt": "2020-03-23T19:30:58.264653Z",
  "updatedAt": "2020-03-23T19:30:58.689007Z",
  "request": {
    "attributionDays": "",
    "campaignId": 1,
    "campaigns": [
      12558
    ],
    "dateFrom": "2020-03-01",
    "dateTo": "2020-03-20",
    "from": "2020-03-01T00:00:00Z",
    "groupBy": "DATE",
    "objects": [],
    "to": "2020-03-20T00:00:00Z"
  },
  "link": "string",
  "kind": "STATS"
}
```

**Ошибка:** `default` — ошибка запроса.

## Список отчётов, сгенерированных через интерфейс

```http
GET /api/client/statistics/list
```

Метод для получения списка отчётов, которые сгенерированы через интерфейс рекламного кабинета.

### Параметры запроса (query)

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `page` | integer \<int64\> | Нет | Номер страницы |
| `pageSize` | integer \<int64\> | Нет | Размер страницы |

### Ответ 200 — Список отчётов

| Поле | Тип | Описание |
|---|---|---|
| `items` | array of objects | Список отчётов |
| `items[].campaigns` | array of objects | Кампании, по которым сформирован отчёт: `id` — идентификатор, `title` — название |
| `items[].meta` | object | Метаданные отчёта: `UUID`, `state`, `createdAt`, `updatedAt`, `request` (структура исходного запроса), `error`, `link`, `kind` |

## Получить отчёты

```http
GET /api/client/statistics/report
```

## Отчёт по поисковым запросам

```http
POST /api/client/statistics/phrases
```

> Метод находится на стадии тестирования.

Формирует отчёт по поисковым запросам. Отчёт можно сформировать только для кампаний с оплатой за клик с признаком `placement = PLACEMENT_TOP_PROMOTION`.

Чтобы запросить отчёт в формате JSON, добавьте в адрес метода `/json` и отправьте запрос по адресу `/api/client/statistics/phrases/json`.

### Тело запроса

| Поле | Тип | Обязательный | Описание |
|---|---|---|---|
| `campaigns` | array of string \<uint64\> | Нет | Список кампаний |
| `dateFrom` | string | Нет | Начальная дата периода отчёта в формате ГГГГ-ММ-ДД. Например: `2019-02-10`. Дата не может быть раньше 1 февраля 2025 года |
| `dateTo` | string | Нет | Конечная дата периода отчёта в формате ГГГГ-ММ-ДД. Например: `2019-02-10` |
| `from` | string \<date-time\> | Нет | Начальная дата периода отчёта в формате RFC 3339. Дата не может быть раньше 1 февраля 2025 года |
| `to` | string \<date-time\> | Нет | Конечная дата периода отчёта в формате RFC 3339 |
| `groupBy` | string | Нет | Тип группировки по времени. Default: `NO_GROUP_BY`. Enum: `DATE` — группировка по дате (по дням); `START_OF_WEEK` — группировка по неделям; `START_OF_MONTH` — группировка по месяцам |

### Ответ 200 — Отчёт по поисковым запросам

| Поле | Тип | Описание |
|---|---|---|
| `UUID` | string | Уникальный идентификатор отправленного запроса. По нему можно проверить статус формирования отчёта и скачать отчёт |
| `vendor` | boolean | Если запрашивается отчёт с аналитикой внешнего трафика — `true` |

**Пример запроса:**

```http
POST /api/client/statistics/phrases HTTP/1.1
Host: api-performance.ozon.ru:443
Content-Type: application/json
Accept: application/json
Authorization: Bearer <token>
```

```json
{
  "campaigns": [
    "string"
  ],
  "dateFrom": "string",
  "dateTo": "string",
  "from": "2019-08-24T14:15:22Z",
  "to": "2019-08-24T14:15:22Z",
  "groupBy": "NO_GROUP_BY"
}
```

**Пример ответа (200):**

```json
{
  "UUID": "string",
  "vendor": true
}
```

**Ошибка:** `default` — ошибка.
