# Ozon Performance API — Полный справочник (2.0)

> Источник: «Документация Ozon Performance API (2.0)» (PDF), конвертировано в структурированный Markdown для использования в больших языковых моделях (LLM) и RAG-системах.
>
> Актуальность: справочник сверён с официальной онлайн-документацией docs.ozon.ru/api/performance (снимок от 13.10.2026) — совпадают 48/48 операций (методы и пути), параметры запросов и ответов, enum-значения, лимиты, changelog и примеры JSON-запросов/ответов.

**Ozon Performance API** — интерфейс для работы с рекламным кабинетом Ozon: управление рекламными кампаниями, ставками, товарами в продвижении и получение статистики. API предназначен для обмена информацией между системой продавца и Ozon.

По вопросам работы с API обращайтесь в поддержку через личный кабинет Ozon.

## Введение и порядок работы

Чтобы использовать API отчётов по рекламным кампаниям Ozon, получите `client_id` и `client_secret` в вашем личном кабинете:

1. В личном кабинете перейдите на страницу **Настройки → API-ключи**.
2. При необходимости создайте сервисный аккаунт: нажмите **Создать новый аккаунт**.
3. Нажмите на название сервисного аккаунта.
4. Нажмите **Добавить новый ключ**.

Для использования API:

1. Получите авторизационный токен с помощью `client_id` и `client_secret` в сервисе авторизации (см. [Авторизация через API-ключ](#авторизация-через-api-ключ)).
2. Выполните запросы с помощью авторизационного токена. Если срок действия токена истёк, получите новый.

## Авторизация через API-ключ

Для получения авторизационного токена отправьте запрос:

```http
POST /api/client/token HTTP/1.1
Host: https://api-performance.ozon.ru
Content-Type: application/json
Accept: application/json
```

**Тело запроса:**

```json
{
  "client_id": "XYZ@advertising.performance.ozon.ru",
  "client_secret": "b1u5XXDQW3wEqQ7dG...ancMyuhQtMNBI",
  "grant_type": "client_credentials"
}
```

**Параметры запроса:**

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `client_id` | string | Да | Идентификатор клиента, вида `XYZ@advertising.performance.ozon.ru` |
| `client_secret` | string | Да | Секретный ключ клиента |
| `grant_type` | string | Да | Тип авторизации, всегда `client_credentials` |

Сервис авторизации вернёт токен с указанием периода его действия в секундах:

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.WyJFTWhVVU...qTz2XXZBv41h4",
  "expires_in": 1800,
  "token_type": "Bearer"
}
```

**Параметры ответа:**

| Параметр | Тип | Описание |
|---|---|---|
| `access_token` | string | Авторизационный токен (JWT) |
| `expires_in` | integer | Время жизни токена в секундах (по умолчанию 1800 — 30 минут) |
| `token_type` | string | Тип токена, всегда `Bearer` |

Полученный токен передавайте в заголовке каждого запроса: `Authorization: Bearer <access_token>`.

## Авторизация через OAuth-токен

> Доступно только продавцам из России.

Чтобы получить OAuth-токен для доступа к Performance API, создайте частное или публичное приложение и выдайте ему доступ к вашему личному кабинету. После этого вы получите OAuth-токен, который позволит работать с методами Performance API.

Используйте OAuth-токен с методами Performance API согласно уровням доступа, которые вы назначили приложению.

Пример запроса:

```http
POST https://api-performance.ozon.ru/{эндпоинт метода Performance API}
Authorization: Bearer ACCESS_TOKEN
```

## Лимиты на запросы

Общий лимит на количество запросов в сутки — **100 000**.

### Лимиты на работу с кампаниями

| Лимит | Значение лимита |
|---|---|
| Лимит на создание кампаний | в день — 1000; в час — 300 |
| Лимит на копирование кампаний | в день — 1000; в час — 300 |
| Лимит на изменение бюджета и смену стратегии для каждой кампании | в день — 500; в час — 100 |
| Лимиты на количество добавлений товаров в созданную кампанию | в день — 1200 запросов на добавление, не больше 1000 товаров в одном запросе; в час — 200 запросов на добавление, не больше 1000 товаров в одном запросе |
| Лимит на изменение ставок внутри кампании | в день — 6000 запросов на изменение, не больше 10 000 товаров в одном запросе; в час — 500 запросов на изменение, не больше 10 000 товаров в одном запросе |

### Лимиты на выгрузки статистики

Лимиты на выгрузки статистики проверяются в начале формирования отчёта. Лимиты действуют для отчётов из раздела «Статистика».

Одна рекламная кампания = одна выгрузка. Если в запросе несколько кампаний, это считается как несколько выгрузок.

Лимит на количество выгрузок в сутки рассчитывается по формуле: `количество активных кампаний × 240` — но не больше значения из таблицы ниже.

| Лимит | Значение лимита |
|---|---|
| Лимит на количество дней в выгрузке | 62 |
| Лимит на количество кампаний в отчёте | 10 |
| Лимит на количество одновременных выгрузок с аккаунта | 1 |
| Лимит на количество выгрузок за 24 часа с аккаунта | 2000 |
| Лимиты на количество одновременных выгрузок по организации | 5 |
| Лимит на количество выгрузок за 24 часа в рамках организации | 2000 |

## Общие соглашения и форматы

### Асинхронность отчётов

Performance API асинхронный для генерации отчётов. Порядок работы:

1. Отправьте запрос на генерацию отчёта (например, `POST /api/client/statistics`).
2. В ответе получите уникальный идентификатор запроса (`UUID`).
3. Проверяйте статус формирования отчёта методом `GET /api/client/statistics/{UUID}`.
4. Когда статус станет `OK`, скачайте отчёт по ссылке из поля `link` методом `GET /api/client/statistics/report`.

### Форматы отчётов

- Формат отчёта по умолчанию — **CSV**; при нескольких кампаниях в запросе — **ZIP-архив** с файлом `<идентификатор кампании>.csv` для каждой кампании.
- Для большинства генераторов отчётов доступен формат **JSON**: добавьте `/json` в адрес метода (например, `/api/client/statistics/json`).

### Ключевые перечисления (enum)

**Тип оплаты кампании (`paymentType`):**

| Значение | Описание |
|---|---|
| `CPC` | Оплата за клики |
| `CPM` | Оплата за 1000 показов |
| `CPO` | Оплата за заказы |

**Тип рекламируемого объекта (`advObjectType`):**

| Значение | Описание |
|---|---|
| `SKU` | Оплата за клик |
| `BANNER` | Баннерная рекламная кампания |
| `SEARCH_PROMO` | Оплата за заказ |
| `VIDEO_BANNER` | Видеобаннер |

**Состояние кампании (`state`):**

| Значение | Описание |
|---|---|
| `CAMPAIGN_STATE_RUNNING` | Активная кампания |
| `CAMPAIGN_STATE_PLANNED` | Кампания, сроки проведения которой ещё не наступили |
| `CAMPAIGN_STATE_STOPPED` | Кампания, приостановленная из-за нехватки бюджета |
| `CAMPAIGN_STATE_INACTIVE` | Кампания, остановленная владельцем |
| `CAMPAIGN_STATE_ARCHIVED` | Архивная кампания |
| `CAMPAIGN_STATE_MODERATION_DRAFT` | Отредактированная кампания до отправки на модерацию |
| `CAMPAIGN_STATE_MODERATION_IN_PROGRESS` | Кампания, отправленная на модерацию |
| `CAMPAIGN_STATE_MODERATION_FAILED` | Кампания, непрошедшая модерацию |
| `CAMPAIGN_STATE_FINISHED` | Кампания завершена: дата окончания в прошлом, изменить нельзя, можно только клонировать или создать новую |
| `CAMPAIGN_STATE_UNKNOWN` | Состояние не определено (значение по умолчанию) |

**Место размещения продвигаемых товаров (`placement`):**

| Значение | Описание |
|---|---|
| `PLACEMENT_INVALID` | Не определено |
| `PLACEMENT_PDP` | Карточка товара. Доступно только для кампаний с ручным управлением |
| `PLACEMENT_SEARCH_AND_CATEGORY` | Поиск и рекомендации |
| `PLACEMENT_TOP_PROMOTION` | Поиск |
| `PLACEMENT_OVERTOP` | Поиск и главная (Спецразмещение) |
| `PLACEMENT_TAKEOVER` | Одновременный показ товаров на первых 4 плитках (устаревает) |
| `PLACEMENT_TILE_MAIN` | Главная, нативный баннер |

**Автостратегия кампании (`productAutopilotStrategy`):**

| Значение | Описание |
|---|---|
| `MAX_VIEWS` | Максимальное количество показов |
| `MAX_CLICKS` | Автостратегия для Поиска и рекомендаций |
| `TOP_MAX_CLICKS` | Автостратегия для Поиска |
| `TAKEOVER` | Спецразмещение для Поиска |
| `TOP_PROMOTION` | Вывод в топ |
| `TARGET_BIDS` | Средняя стоимость клика для Поиска и рекомендаций |
| `TARGET_CIR` | Целевой расход |
| `NO_AUTO_STRATEGY` | Автостратегия не используется |

**Статус автосоздания кампании (`autostopStatus`):**

| Значение | Описание |
|---|---|
| `AUTOSTOP_STATUS_NONE` | Продавец создал кампанию вручную |
| `AUTOSTOP_STATUS_ENABLED` | Кампания создана автоматически и остановится, когда кончатся баллы |
| `AUTOSTOP_STATUS_DISABLED` | Кампания создана автоматически, но она не остановится, когда кончатся баллы |
| `AUTOSTOP_STATUS_STOPPED` | Баллы закончились, кампания остановлена автоматически |

**Статус формирования отчёта (`state` в ответе `GET /api/client/statistics/{UUID}` и `GET /api/client/vendors/statistics/{UUID}`):**

| Значение | Описание |
|---|---|
| `NOT_STARTED` | Запрос ожидает выполнения |
| `IN_PROGRESS` | Запрос выполняется в данный момент |
| `CANCEL` | Формирование отчёта отменено (только в `vendors/statistics/{UUID}`) |
| `OK` | Запрос успешно выполнен |
| `ERROR` | Выполнение запроса завершилось ошибкой |
| `TIMEOUT` | Время ожидания истекло (только в `vendors/statistics/{UUID}`) |

**Тип отчёта (`kind`):**

| Значение | Описание |
|---|---|
| `STATS` | Отчёт по кампании |
| `SEARCH_PHRASES` | Отчёт по поисковым фразам и по категории товаров |
| `ATTRIBUTION` | Отчёт по заказам для оплаты за заказ |
| `VIDEO` | Отчёт по показам видеобаннера |
